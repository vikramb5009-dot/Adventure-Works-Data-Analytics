# Adventure Works SQL Analysis

This section contains SQL queries used to analyze the Adventure Works dataset and answer key business questions.

## Analysis Areas

- Total sales and profit
- Monthly and yearly sales trends
- Top-performing products
- Top customers
- Customer segmentation
- Regional performance
- Product profitability
- Sales and profit by category

## Tools Used

- SQL
- Aggregate Functions
- GROUP BY
- JOINs
- Subqueries
- CASE Statements
- Window Functions
